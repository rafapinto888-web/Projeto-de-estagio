================================================================================
O QUE PRECISAS DE PERCEBER (VERSAO HONESTA - CHEGA)
================================================================================
1. VM na mesma rede que o PC (Bridged) - IP tipo 192.168.1.63
2. Frontend no Windows a ouvir em 0.0.0.0:5173 ou pelo menos acessivel na LAN
3. API no Windows a ouvir em 0.0.0.0:8000 (nao so 127.0.0.1)
4. Nginx na VM:
   - porta 80  -> frontend no Windows (5173)
   - porta 8000 -> API / Swagger no Windows (8000)
5. Abrir no browser:
   - http://IP-DA-VM/             -> site
   - http://IP-DA-VM:8000/docs    -> Swagger via proxy
6. Firewall Windows a deixar entrar na porta 8000
7. Se o frontend pela VM abrir mas a API falhar, o problema costuma ser CORS

Reverse proxy em uma frase: Nginx = ponte; frontend/API = destino no teu PC.

================================================================================
PARTE F - CONFIGURAR NGINX (REVERSE PROXY: FRONTEND + SWAGGER)
================================================================================

F.1  Ativar site default (se precisares):

sudo ln -sf /etc/nginx/sites-available/default /etc/nginx/sites-enabled/default

F.2  Editar ficheiro:

sudo nano /etc/nginx/sites-available/default

F.3  APAGA O FICHEIRO TODO E DEIXA APENAS ISTO
      (SEM # nas linhas activas; troca IP Windows):

server {
    listen 80 default_server;
    listen [::]:80 default_server;

    server_name _;

    location / {
        proxy_pass http://192.168.1.4:5173;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

server {
    listen 8000;
    listen [::]:8000;

    server_name _;

    location / {
        proxy_pass http://192.168.1.4:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

F.4  ERROS QUE PARTEM O nginx -t (NAO REPETIR)

  proxy_sey_header     -> ERRADO -> proxy_set_header
  proxy_set_heder      -> ERRADO -> proxy_set_header
  proxy_pass ... 8080  -> ERRADO -> porta 8000 da API
  proxy_pass ... 8300  -> ERRADO -> porta 8000 da API
  proxy_pass ...:5174  -> ERRADO -> aqui o Vite esta em 5173
  meter server { ... } dentro de outro server { ... }
                       -> ERRADO -> "'server' directive is not allowed here"
  # na frente de location ou proxy_pass
                       -> Nginx ignora = nao funciona

F.5  GRAVAR NANO:
  Ctrl+O -> Enter
  Ctrl+X

  Colar no terminal Ubuntu: Ctrl+Shift+V (nao Ctrl+V)

F.6  APLICAR:

sudo nginx -t
sudo systemctl reload nginx

SAIDA OK:
  nginx: the configuration file ... syntax is ok
  nginx: configuration file ... test is successful

F.7  Ver se proxy_pass esta no ficheiro certo:

grep proxy_pass /etc/nginx/sites-enabled/default

    location / {
        proxy_pass http://192.168.1.4:5173;
        proxy_http_version 1.1;

        proxy_set_header Connection "upgrade";
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

server {
    listen 8000;
    listen [::]:8000;

    server_name _;

    location / {
        proxy_pass http://192.168.1.4:8000;

        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

PARTE I - PROBLEMAS E SOLUCOES (TODOS OS QUE APARECERAM)
================================================================================

I.1  nginx: test failed / unknown directive "proxy_sey_header"
     -> Typo: tem de ser proxy_set_header (set + header)

I.2  invalid number of arguments in "proxy_pass"
     -> URL partida em 2 linhas; falta ; no fim; espacos a mais

I.3  504 Gateway Timeout no browser (http://IP-DA-VM ou :8000)
     -> Nginx OK mas nao chega ao Windows: firewall, servico parado, IP errado

I.4  502 Bad Gateway
     -> Mesma causa que I.3

I.5  Frontend abre mas login / pedidos a API falham
     -> faltou acrescentar http://IP-DA-VM em INVENTARIO_CORS_ORIGINS
        e reiniciar a API

I.6  nginx: test failed / "'server' directive is not allowed here"
     -> Colaste um bloco server { ... } dentro de outro;
        apaga o ficheiro todo e volta a colar

I.7  Welcome nginx mas / ou :8000/docs nao abrem como esperado
     -> o default ainda tem try_files ou config antiga;
        confirma com:
        cat /etc/nginx/sites-available/default

I.8  Site so na VM, nao no Windows
     -> NAT em vez de Bridged

I.9  npm ENOENT package.json
     -> cd frontend antes de npm.cmd (nao na raiz do projeto)

I.10  Pasta sites-enable nao existe
      -> O nome certo e sites-enabled (com d no fim)

I.11  Repor config default quebrada:

sudo apt install --reinstall nginx -y
# depois volta a Parte F
