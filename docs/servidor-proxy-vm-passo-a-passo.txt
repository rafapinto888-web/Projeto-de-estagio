================================================================================
O QUE PRECISAS DE PERCEBER (VERSÃO HONESTA — CHEGA)
================================================================================
1. VM na mesma rede que o PC (Bridged) — IP tipo 192.168.1.63
2. API no Windows a ouvir em 0.0.0.0:8000 (não só 127.0.0.1)
3. Nginx na VM: quem pede http://IP-DA-VM → encaminha para http://IP-WINDOWS:8000
4. Abrir no browser: http://IP-DA-VM/docs (Swagger via proxy)
5. Firewall Windows a deixar entrar na porta 8000 (senão dá 504 Gateway Timeout)

Reverse proxy em uma frase: Nginx = ponte; API = destino no teu PC.

================================================================================

# Depois de editar config (sempre):
sudo nginx -t
sudo systemctl reload nginx

# Se precisares reiniciar à força:

# Parar Nginx:
sudo systemctl stop nginx

# Firewall VM (se ufw estiver active e noutro PC não abrir):
sudo ufw status
sudo ufw allow 80/tcp
sudo ufw reload

PARTE F — CONFIGURAR NGINX (REVERSE PROXY)
================================================================================

F.1  Ativar site default (se precisares):

sudo ln -sf /etc/nginx/sites-available/default /etc/nginx/sites-enabled/default

F.2  Editar ficheiro:

sudo nano /etc/nginx/sites-available/default

F.3  DENTRO de  server { ... }  :

  - MANTÉM: listen 80 default_server;
  - MANTÉM: listen [::]:80 default_server;
  - APAGA o bloco antigo:

    location / {
        try_files $uri $uri/ =404;
    }

  - COLA ISTO (SEM # nas linhas activas; troca IP Windows):

    location / {
        proxy_pass http://192.168.1.43:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

F.4  ERROS QUE PARTEM O nginx -t (NÃO REPETIR):

  proxy_sey_header     →  ERRADO  →  proxy_set_header
  proxy_set_heder      →  ERRADO  →  proxy_set_header
  proxy_pass ... 8080  →  ERRADO  →  porta 8000
  proxy_pass ... 8300  →  ERRADO  →  porta 8000
  # na frente de location ou proxy_pass  →  Nginx ignora = não funciona

F.5  GRAVAR NANO:
  Ctrl+O  → Enter
  Ctrl+X

  Colar no terminal Ubuntu: Ctrl+Shift+V (não Ctrl+V)

F.6  APLICAR:

sudo nginx -t
sudo systemctl reload nginx

SAÍDA OK:
  nginx: the configuration file ... syntax is ok
  nginx: configuration file ... test is successful

F.7  Ver se proxy_pass está no ficheiro certo:

grep proxy_pass /etc/nginx/sites-enabled/default

================================================================================
PARTE F-BIS — MÉTODO ALTERNATIVO (ESCREVER FICHEIRO INTEIRO DE UMA VEZ)
================================================================================
Se o nano for chato, na VM (troca 192.168.1.43 pelo IP Windows):

sudo bash -c 'cat > /etc/nginx/sites-available/default << "ENDOFFILE"
server {
    listen 80 default_server;
    listen [::]:80 default_server;

    server_name _;

    location / {
        proxy_pass http://192.168.1.43:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
ENDOFFILE'

sudo ln -sf /etc/nginx/sites-available/default /etc/nginx/sites-enabled/default
sudo nginx -t
sudo systemctl reload nginx

PARTE I — PROBLEMAS E SOLUÇÕES (TODOS OS QUE APARECERAM)
================================================================================

I.1  nginx: test failed / unknown directive "proxy_sey_header"
     → Typo: tem de ser proxy_set_header (set + header)

I.2  invalid number of arguments in "proxy_pass"
     → URL partida em 2 linhas; falta ; no fim; espaços a mais

I.3  504 Gateway Timeout no browser (http://IP-DA-VM)
     → Nginx OK mas não chega ao Windows: firewall 8000, API não 0.0.0.0, IP errado

I.4  502 Bad Gateway
     → Mesma causa que I.3

I.5  Welcome nginx mas /docs não abre
     → location / ainda com try_files; proxy_pass não activo

I.6  Site só na VM, não no Windows
     → NAT em vez de Bridged

I.7  npm ENOENT package.json
     → cd frontend antes de npm.cmd (não na raiz do projeto)

I.8  Pasta sites-enable não existe
     → O nome certo é sites-enabled (com d no fim)

I.9  Repor config default quebrada:

sudo apt install --reinstall nginx -y
# depois volta à Parte F
