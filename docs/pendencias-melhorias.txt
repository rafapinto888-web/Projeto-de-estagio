NOTAS DE AMBIENTE (apos seguranca)
----------------------------------------------------------------------

Desenvolvimento local:
  - Editar backend/.env (DATABASE_URL, SECRET_KEY, etc.)
  - INVENTARIO_ALLOW_SWAGGER_BYPASS=true: /docs sem JWT (ou Basic user+password no Authorize)
  - Alternativa Swagger: POST /auth/login, copiar access_token, Authorize Bearer

Producao / demonstracao:
  - SECRET_KEY unica e forte
  - INVENTARIO_ALLOW_SWAGGER_BYPASS=false (ou omitir)
  - INVENTARIO_APP_ENV=production
  - CORS so com o dominio real do frontend

Reiniciar API apos alterar .env:
  cd backend
  .venv\Scripts\python.exe -m uvicorn app.core.main:app --reload --host 127.0.0.1 --port 8000
