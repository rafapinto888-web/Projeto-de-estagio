================================================================================
2) NGINX NA VM (resumo — detalhe no outro ficheiro)
================================================================================
VM Ubuntu: sudo apt install nginx -y
VirtualBox: Rede ponteado (Bridged), não NAT.
IP VM:     hostname -I   (ex. 192.168.1.63)
IP Windows: ipconfig     (ex. 192.168.1.43)

Na VM, ficheiro: /etc/nginx/sites-available/default
  location / {
      proxy_pass http://192.168.1.43:8000;
      proxy_set_header Host $host;
      proxy_set_header X-Real-IP $remote_addr;
      proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
  }
  (trocar 192.168.1.43 pelo IPv4 real do Windows; porta 8000)

sudo nginx -t
sudo systemctl reload nginx

Passo a passo completo: docs\servidor-proxy-vm-passo-a-passo.txt
