================================================================================
1) CORRER SEM DOCKER (recomendado para scan na LAN — API no Windows)
================================================================================
Precisas: PostgreSQL a correr, ficheiro backend\.env com DATABASE_URL, SECRET_KEY, CORS, etc.

--- Terminal 1 — API (porta 8000) ---
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.core.main:app --reload --host 127.0.0.1 --port 8000

# Para a API ouvir na rede local (outros PCs):
# .\.venv\Scripts\python.exe -m uvicorn app.core.main:app --reload --host 0.0.0.0 --port 8000
# (define INVENTARIO_CORS_ORIGINS com o URL do frontend, ex.: http://192.168.1.10:5173)

Swagger: http://127.0.0.1:8000/docs

--- Terminal 2 — Frontend (Windows) ---
cd frontend

# PowerShell bloqueia npm.ps1 (Execution Policy)? Usa npm.cmd:
npm.cmd install
npm.cmd run dev
# Site: http://127.0.0.1:5173

# Se o Docker ja tiver o frontend na porta 5173, corre o Vite LOCAL na 5174 (Docker continua igual):
npm.cmd run dev:local
# Site: http://127.0.0.1:5174
# (acrescenta esta origem em INVENTARIO_CORS_ORIGINS no backend\.env se a API recusar pedidos)

# Alternativa: duplo clique em frontend\dev-local.cmd

--- Parar ---
Ctrl+C em cada terminal.

2) DOCKER (resumo)
================================================================================

cd "C:\Users\Jose\Desktop\Projeto de estagio"

# --- OUTRO PC (copiar projeto + Docker Desktop) ---

# 1) Dev com hot reload (só frontend em container; API costuma ser no PC)
.\scripts\docker-subir-dev.ps1
# ou:
docker compose --profile dev-live up -d --build web-dev

# 2) Tudo em Docker (frontend dev + API + Postgres)
.\scripts\docker-subir-tudo.ps1
# ou:
docker compose --profile dev-live --profile docker-api --profile bundled-db up -d --build

# Se deps npm falharem (ex. xlsx), recriar volume e rebuild:
docker compose --profile dev-live down
docker volume ls
# apaga o volume node_modules do frontend se existir, depois:
docker compose --profile dev-live up -d --build web-dev

# --- MODOS ---

# Subir frontend DEV (auto-atualiza ao editar)
docker compose --profile dev-live up -d --build web-dev

# Subir frontend + backend + base de dados
docker compose --profile dev-live --profile docker-api --profile bundled-db up -d --build

# Subir frontend + backend (API usa Postgres do PC via host.docker.internal)
docker compose --profile dev-live --profile docker-api up -d --build

# Ver estado
docker ps
docker compose ps

# Ver logs
docker compose logs -f
docker compose logs -f frontend-dev
docker compose logs -f backend
docker compose logs -f base-de-dados

# Parar
docker compose stop
docker compose down
